# @appswyldesolutions/vcv-core

## 1.0.0

First public release on npm.

- The value chain KPI logic, extracted from the prototype: `KpiRow` and
  `Theme` types, `fromWideRecords` and `fromLongRows` ingestion, `evaluate`
  and `formatValues` for a single row, and `buildModel` to group rows into a
  `ValueChainVisualiserModel` for a selected year and period.
- ESM with type declarations; `main`, `types` and `exports` point at `dist`.
