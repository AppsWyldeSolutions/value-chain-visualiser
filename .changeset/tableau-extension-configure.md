Tableau extension: a Configure dialog (Configure… in the extension zone's
menu) maps any worksheet's fields to the visual's, so a worksheet no
longer needs fields named after them. The mapping is saved in the
workbook's extension settings. Without one, the extension reads the
fields by name, as before; the dialog opens by itself when an author adds
it to a worksheet without those names.
